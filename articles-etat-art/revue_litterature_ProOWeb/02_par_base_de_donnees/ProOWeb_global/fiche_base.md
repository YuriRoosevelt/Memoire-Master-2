# Fiche globale ProOWeb

Cette fiche regroupe la stratégie documentaire réellement utilisée pour la revue ProOWeb.

## Orientation

La recherche documentaire est centrée sur les travaux permettant de passer de modèles BPMN ou de modèles métier vers des applications web, des interfaces, des artefacts logiciels ou des workflows exécutables.

## Sources mobilisées

- SpringerLink : articles MDE, low-code, PAIS, workflows.
- ICEIS : article AKIP sur les applications web process-aware.
- LACCEI : cartographie des outils de développement web dirigé par les modèles.
- Frontiers : revue sur la transformation automatique entre artefacts logiciels.
- IJACSA : génération d'interfaces depuis BPMN via IFML.
- Google Scholar : repérage transversal, vérification des DOI et accès aux versions PDF.

## Familles d'articles retenues

1. PAIS et applications web orientées processus.
2. BPMN enrichi et génération.
3. Assistance à la modélisation BPMN.
4. Développement web dirigé par les modèles.
5. Low-code et MDE.
6. Workflows, données et artefacts intermédiaires.

## Comment utiliser cette fiche

Cette fiche doit être utilisée comme référence principale pour la rédaction. Les anciennes fiches du dossier portant sur les chatbots LLM et les API REST/OpenAPI sont hors périmètre pour la revue ProOWeb.
