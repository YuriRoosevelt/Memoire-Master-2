# Corpus initial pour l'etat de l'art

Ce dossier contient 10 articles ouverts et pertinents pour construire l'etat de l'art du memoire sur ProOWeb.

## Articles telecharges

1. `01-van-der-aalst-2013-bpm-comprehensive-survey.pdf`
   - Axe : fondements du Business Process Management.
   - Utilite : expliquer le role des processus metier dans les systemes d'information.

2. `02-drave-michael-2022-mde-process-aware-information-systems.pdf`
   - Axe : model-driven engineering pour les process-aware information systems.
   - Utilite : article tres proche de ProOWeb, notamment sur BPMN, generation et integration avec code manuel.

3. `03-blal-2025-soa-services-identification-business-models-slr.pdf`
   - Axe : identification de services SOA depuis des modeles metier.
   - Utilite : montrer que la transformation du metier vers l'architecture logicielle est un probleme reconnu.

4. `04-syriani-2017-template-based-code-generation-mapping.pdf`
   - Axe : generation de code par templates.
   - Utilite : justifier l'usage de templates, mais aussi discuter leurs limites de maintenance et gouvernance.

5. `05-hoyos-restrepo-2017-web-process-oriented-code-generation.pdf`
   - Axe : generation automatique d'applications web orientees processus.
   - Utilite : article directement relie a la generation de prototypes web a partir de processus.

6. `06-birkmeier-2009-service-identification-survey.pdf`
   - Axe : identification de services.
   - Utilite : construire la partie SOA et alignement entre fonctions metier et services logiciels.

7. `07-neto-2022-akip-process-aware-web-applications.pdf`
   - Axe : plateforme de developpement d'applications web process-aware.
   - Utilite : comparaison directe avec ProOWeb, notamment sur BPMN, code generation et limites des plateformes BPA.

8. `08-hemel-2008-webworkflow-web-applications.pdf`
   - Axe : langage de workflow pour applications web.
   - Utilite : montrer les travaux anterieurs reliant workflows et developpement web.

9. `09-castillo-davila-2024-model-driven-web-development-tools-mapping.pdf`
   - Axe : outils de developpement web dirige par les modeles.
   - Utilite : cadrer ProOWeb par rapport aux outils MDWD et a la generation web.

10. `10-frontiers-2023-auto-generating-transformation-artifacts-review.pdf`
    - Axe : transformations automatiques entre artefacts de developpement logiciel.
    - Utilite : soutenir la partie sur transformations, tracabilite et passage exigences/modeles/code.

## Remarque

Ce corpus constitue une base initiale. Il pourra etre complete ensuite par des articles plus specifiques sur Camunda, Flowable, Bonita, la verification BPMN, la variabilite des processus et les plateformes low-code.
